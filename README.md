# 数据集的处理
该数据集有约六十七万张图片，十分庞大，我的4060笔记本训练较为困难，为此我对数据集进行了缩小处理：  
1.数据集汇总了正面，左面，右面，第一人称，第三人称的大量图片，我只选择了第三人称正面的图片。
2.在选取的所有第三人称正面图片中，我在每个文件夹中都选择了前2000张照片，汇总成了一个新的小数据集
3.数据标注：数据集并未进行数据标注，为此我使用cocos对yolo进行预处理，通过该预处理之后的权重来对我构建的小数据集进行统一的标注
4.数据划分：我将标注好的所有数据按照8:2来划分训练集与验证集，并以此来训练yolo人体姿态识别模型
# 锻炼动作评分
识别了人体之后，锻炼评分最重要的就是对锻炼动作的数学处理，在这里我参考了一篇[基于人体姿态估计的健身运动评估系统](10.3969/j.issn.2095-1248.2026.01.009)的论文，通过该论文我初步构建了健身运动评估系统的框架，但是经过我的实际测试，仅使用原文中的公式并不足以对运动进行准确的评估，因此我又
参考了[基于Mediapipe单人运动姿态评测系统的研究与开发](10.27796/d.cnki.ghbsf.2023.000310),基于上述两篇论文，我终于构建出了较为完善的健身运动评估系统，同时经过我自己的微调，以及自己构建的几个小公式，我构建出了现在的锻炼牛牛v1.0.0版本。具体锻炼评分细则可参考代码内容，由于时间原因我在这里
不进行讲解，以后可能会写一篇小论文来详细阐述。
